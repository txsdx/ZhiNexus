## 当前验证记录

- `npm test`：16 项核心/模型目录测试通过（CRDT 乱序、重复、并发与因果解决，日志篡改与缺口，加密/错误密码/篡改，FSRS，CPA 回退与未知能力）。
- `npm run build`：TypeScript 与 Vite 生产构建通过；图和渲染依赖按需加载，仍存在大 chunk 优化提示。
- Playwright：9 项浏览器集成通过（包括自动捕获整理、分类/Agent确认、加密图片备份、双设备同步、同配置文件多标签页并行写入、加密凭证保险箱跨设备解锁），隔离服务最终运行 30.1 秒。
- `cargo check`、`cargo build --locked`：Linux 通过；原生启动发现并修正 updater 缺省配置问题。
- 原生运行：插件已初始化到 WebKit 启动，但 WebKitNetworkProcess 要求 `/usr/lib/...` 的固定系统安装位置；当前只有无 root 的 sysroot，故未完成原生窗口功能验证。没有禁用 TLS 或 WebKit sandbox。
- Android/Windows/macOS 安装包、签名更新、真实 AI/WebDAV/MCP：未运行；不能宣称验证通过。

4. 桌面完全退出后不发送通知；开启后台常驻才会继续运行。Android 强停、权限/省电策略会影响排程，重开会重建。
5. 迁移保留源和旧目标，按当前数据集复制，不合并两套数据库。不可写运行目录需先把程序移到可写位置。极端断电/磁盘故障和所有平台混合 DPI/多屏仍需扩大验证。
6. API Key 默认内置密钥为用户指定的便捷包装，随程序分发，不对获得程序的人保密。支持自定义同步密钥，但未接 OS Keychain，知识正文未 E2EE。WebDAV/MCP 密码保险箱仍需修改后手动封存；无设备撤销/密钥轮换管理。
7. stdio 只支持桌面；自定义子进程网络由其自身环境变量决定。外部 MCP 中断后不能保证幂等，Agent 会要求确认重试。
8. WebDAV 无全局原子快照；并发/中断可能需后续交换收敛。普通增量不会重下载所有已知文件，显式深度审计可隔离坏块并从可信同 hash 副本修复。
9. 一事件一文件、Depth-1 全名字发现、本地全日志投影；尚无有界日志块、索引投影、增量 Merkle 子树和大库性能验证。CRDT 按整字段保留并发值，不是逐字符文本合并。
10. 完整备份/快照在内存构建；导入上限 256 MiB、单附件 20 MiB。只在校验成功后安全清理恢复冗余/pending；不自动删除历史/孤儿附件，不承诺任何故障下绝不丢失；无可信副本时保留原文件并报错。
11. 全库 AI 分类受上下文上限影响；部分底层错误/模板待继续双语化。中文字体/Mermaid/图编辑包较大，仍有 chunk 提示，低端手机性能待测。
12. 正式 Release 安装升级尚未端到端验证。Android 连续覆盖升级需稳定签名证书；无用户证书的 CI APK 为开发证书。Release 上传使用自动 GITHUB_TOKEN，与可选签名不同。已配置 Minisign 公钥不可跳过验证；Windows Authenticode 未配置。

## 0.6 校验边界

- 显式校验会读取全部云端日志、附件、快照，代价高于平时增量同步。连续并发变更最多重试三轮，之后保留已合并内容并提示重试，不清理。
- 无全局原子 WebDAV 锁；校验报告代表已读取的稳定发布集合，无法感知离线设备尚未上传的记录。不可修复的文件/坏快照均保留报错，不以忽略坏文件来报告成功。
- 清理必须有三份已验证快照覆盖同一条恢复记录；新近条目可能暂不清理。损坏原件、迁移备份、历史附件和远端日志保持保留，空间仍会增长，尚无设备撤销/全历史 GC。
- 原生网络权限修复需要安装本轮新包；旧的已安装程序不能靠修改 API 地址或 WebDAV 设置获得新的 capability。

- OpenAI 兼容 API 的根地址通常需包含 `/v1`：根路径 `/models` 的 HTTP 404 与网络权限错误不同。只读未认证探测不能证明凭证或所有接口兼容。


## 0.7 起的编辑与构建边界

- 所见即所得覆盖常用 Markdown、公式、Mermaid、任务和表格；脚注/原始 HTML 保留源码编辑，避免转换丢失。文本仍按整字段 CRDT 合并，不是逐字协作。
- 未保存草稿/标签/聚焦范围按设备保存在本机；保存词条后才参与同步和知识快照备份。切换标签保留草稿与后台页面任务；编辑器撤销栈只在当前挂载视图内保留。
- 大纲和聚焦以顶层块/标题章节为单位；尚无思源的块引用/嵌入、SQL 嵌入、分屏、PDF 标注等完整功能。尚未进行百万字文档或大量标签性能测试。
- Windows、Linux、Android 的 Rust/系统依赖不能共用二进制编译产物。统一 Action 复用前端并分别缓存原生工具链；耗时仍受 Rust 链接、缓存传输和模拟器启动影响，不能承诺固定倍数加速。

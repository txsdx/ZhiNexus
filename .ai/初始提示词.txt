【二、定位、平台和工程基础】
7. 软件用于每天捕获、理解、长期记忆概念；中文名“知枢”，英文名“ZhiNexus”。本地优先、离线可用，多设备同步。
8. 支持 Windows x64、Ubuntu 24.04+ x64、Android 15+/API35 arm64-v8a。无需 macOS 交付。UI 支持简中/English/系统语言、鼠标键盘及手机布局。
9. 使用 Tauri 2、React 19、TypeScript 5.9、Vite 6；SQLite 是本地权威库。桌面/Android 原生用 Tauri SQL/sqlx 0.8；浏览器预览用 sql.js/WASM 和 IndexedDB。
10. 使用成熟库与公开 API：Tiptap 3/ProseMirror/Markdown、ts-fsrs 5.x、React Flow/XYFlow 12、Dagre、Fuse、Zod 4、KaTeX、Mermaid、官方 MCP SDK 1.x、eventsource-parser、Tauri 官方插件。用锁文件固定实际版本，不关闭 TLS/校验/测试来绕过问题。
11. TS 负责领域、工作流和 UI，Rust 负责 OS 边界、原生存储恢复、网络与更新安装等。模块分离：src/core、src/services、src/components、src/pages、src/hooks；src-tauri/src 和 mobile/android；scripts、tests、.ai。
12. 源文件有概述，新增导出类型和函数有注释，Prettier/Rustfmt 格式化。快速迭代不要求兼容旧开发数据库，但不得靠重置/删库规避现有用户数据。
13. 品牌图标为高质量透明 1024×1024；希望使用 image-2.5。若工具不能选择或确认模型，必须如实说明。资源离线打包，字体不依赖在线 CDN。

【三、知识捕获、查询与词条】
14. 快速/模糊查询标题、正文、标签，重复名称优先复用已有词条；用户再次调取相似概念可进入学习/复习，不能不断创建重复条目。
15. 原始材料先持久保存，再提交 AI 整理任务。AI 失败不能损失原文，错误可见、可重试。支持快捷捕获选中文字、截图 OCR、图片附件、来源应用/进程信息。
16. 词条结构按需包含：英文名/翻译、已知 IPA（可多个）、一句话解释、中文详解、标准定义/公式、条件/边界、直观类比、案例/反例、常见误区、自测、前置知识和关联。未知信息明确未知，不编造来源。
17. 支持 Markdown、LaTeX/KaTeX、严格模式 Mermaid、表格、代码、图片；渲染不执行原始脚本，远程 Markdown 不能自动跟踪加载图片。图片用已校验 asset:<hash> 引用。
18. 提供 Tiptap 块式所见即所得、持久块 ID、左侧文档大纲、块聚焦、多标签、本机草稿重启恢复。参考思源相关交互，但不能复制无关复杂性。
19. 大纲点击立即定位，不能平滑滚动。聚焦编辑只能替换可见范围，删除标题也不能吞掉隐藏段落。复杂 Markdown 保留源码编辑入口，避免无损转换失败。
20. 阅读页给长标题完整宽度，避免被属性栏挤成难看的断行；属性编辑栏仅在编辑时显示。复习次数、下次复习放在创建/最近更新时间右侧，两列各两行对齐，窄屏可整块换行。
21. 词条页不再放右侧“一句话解释”和“知识连接”卡片。大纲放左侧。历史、编辑、词条 AI 入口集中在标题操作区。
22. 添加图片与 AI 配图：配图提示词弹窗预填可配置模板，明确提交后生成，结果审阅后插入当前最新草稿，不能覆盖生成期间的新编辑。
23. 划词工具条提供 AI 对话、复制、黄色高亮、取消高亮、加粗等；编辑/阅读批注都要保留选区、撤销和正文完整性。
24. 词条背景色支持默认、柔和浅红/绿/蓝/黄/紫；对比度足够，夜间有对应色，色值用白名单 token 保存并同步。知识列表、词条和星图展示一致。
25. 添加、重命名、移动、正文改动、图片增删等可审计；保留创建/更新时间、来源、CRDT 历史、回收站和冲突处理。

【四、列表、分类树与删除】
26. 知识库使用紧凑分类树表格，不使用大面积卡片。递归计数、折叠/展开、排序、未分类及异常远端层级都不能遗漏/重复条目。
27. 表格四列：标题、一句话解释、紧凑创建日期、下次复习。主要宽度给前两列；下次复习按天数、粗体显示，逾期负数，完整时间可悬停查看；文字使用 FSRS 遗忘程度色，黑→黄→红。删除旧“上次复习”和独立“记忆状态”列。
28. 设置分类树可以直接拖拽修改父子层级，可移回顶层。拒绝自身/后代循环、无效目标、拖拽期间已变化的数据。保留非拖拽的层级编辑方式供键盘/手机使用。
29. 树节点直接有删除按钮，也有分类右键操作。AI 整理前后对照树是只读预览，不能在那里直接修改真实分类。
30. 删除分类提供三种选择：a. 保留条目和子分类，直属内容移到被删分类的上一级；b. 删除整棵子树及层级内全部条目；c. 取消。回车默认 a，破坏性全删必须明确选择。回收站和日志可保留，不执行物理抹除。
31. 所有删除/恢复等确认必须真正等待结果。取消、关闭、Escape、点击遮罩、确认 Promise 拒绝、持久化失败，均不能提前改变数据。分类和关联条目一次原子提交；审阅期间范围变化要拒绝或重新审阅。
32. 普通确认框支持 Enter 确定，且遵循显式聚焦的取消/关闭按钮。防止中文输入法 Enter、按住回车、修饰键和重复点击误确认；确认不能沿用打开弹窗的同一次按键。

【五、AI、模型、任务与内置 Agent】
33. 接 OpenAI Chat Completions 兼容服务；CPA /models?client_version=cpa 按实际格式解析并做有限合理回退。sync_cpa_to_copilot.py 只作读取逻辑参考；不执行或复制其中凭证、私有路径、模型猜测。
34. 模型列表和所有选择框显示原始 ID，例如 gpt-6.1-sol-fast；Tools:? 是未知，允许尝试，明确 false 才禁用。模型、思考档位、上下文与视觉等按实际声明处理，不按名称猜能力。
35. 全局默认模型加“默认模型”选项动态继承；每个任务/对话可覆盖，不覆盖既有单项选择。各任务预设合理思考档位。
36. 所有 AI 文本功能真实流式输出：聊天、分类、解释、评分、关联、OCR 等；正确拼接 UTF-8、思考内容和工具参数。只有服务明确拒绝流式时有限回退完整响应，不伪造流式。图片按实际 API 进度处理。
37. 可配置并自动保存 AI 并发上限（默认2，1–16），一条持久本机任务队列统一调度。显示真实输出/错误，支持停止、排队取消、重试、跳到相关页面、审阅和明确应用。
38. 导航不停止后台任务；审阅不占 HTTP 并发。进行中结果持久保存；重启恢复中断状态但不得自动重放未知外部副作用。多窗口必须有队列所有权保护。
39. 影响知识的分类/解释/配图/关联提案不能提前应用。应用回执与知识写入原子化，清队列失败不能重复应用。只读查询免审阅，完成的聊天/标题等不改数据任务自动清理。
40. 每个 AI 功能有独立可编辑提示词模板，变量字面替换。知识、选中文字、工具输出和附件均是数据，不能作为执行指令。
41. 全局 Agent 有自己的话题历史；每个词条独立上下文和话题历史。词条 AI 是右侧栏，不跳到独立页面；侧栏可展开小话题列表，可关闭，手机适配。
42. 划词自动携带选中文本和上下文。Agent 可以读取已保存正文、当前未保存草稿及必要选择信息；编辑解释优先经审阅后更新本机草稿，显式保存才写入知识。必须防止修改在审阅期间覆盖新的编辑；局部替换匹配不唯一时不能猜。
43. 全局聊天占满可用窗口，外层不滚动，消息区/话题列表独立滚动；提问右对齐；模型和思考设置放输入框下方。支持流式跟随/浏览历史暂停、回到最新、停止/重试、复制、工具细节折叠、Enter发送/Shift+Enter换行、输入法保护。
44. 话题自动标题可双击/按钮编辑；迟到自动标题不能覆盖手动名称。切换话题保留各自草稿。移除开场口号、免责声明和“本地优先…”等占空间的宣传卡片。
45. 内置 tools 至少覆盖：搜索/分页列条目、读完整条目和本机草稿、列/读分类、读复习队列和不含凭证的软件状态；词条创建/编辑/移动/软删除/恢复；分类创建/重命名/移动/保留删除/子树删除；审阅式解释草稿编辑。工具参数独立严格 schema，路径/对象引用校验，写入具体预览、取消检查、幂等回执、并发保护；只读工具免确认。
46. 支持手动启用 MCP：HTTP/Streamable HTTP、SSE、桌面 stdio；放在任务/提示词设置之后。外部只读须明确 readOnlyHint 且无 destructiveHint，才免确认；未知、写入和结果不明回执继续确认。stdio 程序只能来自本机显式配置，不让同步内容自动开启程序。

【六、复习科学、遗忘曲线和通知】
47. 使用维护中的 ts-fsrs，而非手写固定间隔。参考 Anki 官方 FSRS 文档、open-spaced-repetition/FSRS 的算法资料及可靠的间隔学习/提取练习研究；在 .ai 中记录可访问来源、设计依据与限制。
48. 分清检索概率 R（预计能回忆）、稳定性 S（遗忘速度/时间尺度）、难度 D；曲线显示预计回忆概率，不宣称直接测量了用户大脑或把 AI 自评当作实测记忆。
49. 新建知识默认按“已经学过/记住”初始化 FSRS，首次复习安排在未来，不立即进入队列。隐式初始学习不计入用户真实完成的复习次数；保留旧卡历史。可合理提供“仅收集尚未学习”的入口，但不能违背默认已学过。
50. 独立“遗忘曲线”页显示过去和未来时间范围，多词条不同颜色；滚轮平移时间轴，可缩放/回今天。数量可配；按当前预计回忆概率上限筛选（高于上限不显示）。悬停显示词条/概率，点击打开解释。
51. 图上标出当前时间和复习水平阈值。设置中自动保存、同步“期望保留率/复习阈值”，默认90%；较高值会明显增大复习负担，应有简短准确说明。图表、到期时间、队列和调度使用同一份策略，不维护互相矛盾的阈值。
52. 低于目标保留率的已学习词条进入复习队列；未知/尚未学习的词条不伪造曲线。历史曲线从可验证的创建/复习卡片历史重建；未来是预测，不能把当前参数无条件外推为过去的实测记录。
53. 复习采用提取练习：先答题，再看反馈。AI 生成简答/选择，判断理解/迁移、给建议与补教。允许用户根据实际回忆选择“忘记/困难/记得/轻松”，AI 建议不能替代实际回忆感受；显式提交后才更新 FSRS、真实次数和曲线参数。
54. 允许取消复习、重新出题、重新作答（含高分答案），未完成上下文退出可恢复。取消/换题/重试不增加 FSRS 次数；停止请求、防迟到响应和并发覆盖，评分/补教/卡片提交保持一致。
55. 按设备独立设置复习提醒、失焦 AI/OCR 完成、同步失败、预览和冷却。Android 复习提醒用 OS 排程；桌面后台常驻时可提醒。权限/强停限制如实记录，通知失败不让 AI 成功变失败。

【七、同步、校验、备份与凭证】
56. Local-first：SQLite + append-only 操作日志 + 多值字段 CRDT + 因果版本向量 + SHA-256 + Merkle/逻辑状态摘要。每个进程写者 UUID 独立；同写者序号分叉、因果缺口、非法文档要拒绝。
57. 同步 HTTPS WebDAV（含非默认端口和自建 SFTPGo），强制证书/主机名校验，使用全局代理。不能直接覆盖另一台设备的工作 SQLite。
58. 云端用 gzip 不可变操作批次和完整可校验检查点：packs/、checkpoints/、blobs/、quarantine/、state/HEAD.json。默认每批256操作/约1MiB，合法大操作有32MiB硬限；文件含epoch、随机nonce和内容摘要。附件20MiB上限、字节摘要命名、元数据校验。
59. HEAD 原子发布：先探测可靠强 ETag 条件写入；SFTPGo 若忽略条件 PUT，则用经过探测的 WebDAV 排他祖先锁、精确内容版本比较和 If 锁令牌栅栏。验证互斥、无令牌拒绝、过期令牌拒绝；两种原语都不可用则报错，禁止不安全发布/清理。
60. 上传新对象并读回校验后再 CAS HEAD；竞争失败合并重试，不覆盖他人。完整保留已发布因果历史，使长期离线设备和新设备在整理后仍可重建/合并。
61. 自动压缩累积增量批次、复用未变化的活批次。epoch 栅栏只回收不再引用的较旧准备对象；不能复活已扫旧路径。旧读者遇到清理404应重读HEAD重试。
62. 云端只用于同步、不需历史回滚；删除旧逐事件稳态同步/审计引擎和云端回滚 UI。已有松散 events/snapshots/devices 必须先完整验证/合并再一次性转为新结构并回收。普通同步每轮最多256次删除，后续继续，手动整理可完成剩余；失败可重试，未知/坏文件保留报错。所有客户端统一更新新协议。
63. 普通同步跳过本机可重建并验证的已知批次正文。显式深度审计读回云端字节，结合 SQL、原生恢复日志和同摘要缓存修复；坏原件先隔离。无可信副本时，必须在替换 SQL 前拒绝，不能静默丢记录。
64. 校验成功后比较实际本地/云端 Merkle 与逻辑状态，再清理已被三份验证检查点覆盖的本地恢复冗余。保留 SQL 历史、冲突、回收站、历史附件及坏原件。给出准确文件/字节统计，不保证未知故障下绝对不丢失。
65. 自动同步按距上次成功时间的实际间隔；启动已逾期、唤醒、重新联网都要重新判断；手动同步重置成功时间。失败保留时间、退避重试，防手动/审计/多窗口重复执行。没有成功完成就不能显示已同步。
66. 取消“增量同步完成”浮窗。右上角显示“同步过时：X分X秒”，每秒更新且不写数据库；点击立即同步，进行中防重入，刷新后保留成功时间。
67. 保留完整加密文件备份/并集合并恢复、数据库空间显示/VACUUM、冲突解决、回收站。备份恢复凭证额外明确确认。对象存储和专属服务端只预留 SyncTransport，暂不声称已实现。

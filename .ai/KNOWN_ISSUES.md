# 待解决的问题与验证边界

## 0.13 流式与队列边界

- 文本功能使用 Chat Completions SSE；只对服务端明确拒绝流式的 400/422 做一次完整响应兼容，不自动重放断开的生成或外部操作。图片生成使用接口实际进度和最终图片，未伪造文字流；仍需真实私有服务兼容验证。
- 队列按设备保存，最多 100 项，单次流上限 4 MiB、队列加密元数据上限 32 MiB；超限/落盘失败可见报错并保留内存结果，不静默丢弃旧任务。进行中输出约 350 ms 保存一次，强杀仍可能丢失最后一小段；重启必须人工重试。
- 同一浏览器的其他窗口只读镜像，需要切回任务所属窗口操作；关闭所属窗口后重新加载可接管。限流不跨设备，远端已开始的计算不保证停止。已有知识同步继续使用 CRDT，并非跨设备互斥。
- 图片应用先插入最新本机草稿，再由保存词条参与同步。划词高亮以 Markdown `==…==` 存储；有原始 HTML/脚注的内容继续使用源码入口保护原文。
- 本轮平台构建、原生 SSE 和正式 Release 验证仍在进行，完成后更新 STATUS。


1. Windows/Ubuntu 0.8.0 实际安装产物与原生 OCR/代理/stdio/重启/恢复测试、Android 0.8.1 的 API35 模拟器富文本/标签/触控导航/安全区域/存储/通知测试均通过（见 STATUS）。没有 Android 实体手机测试；不能据此保证所有硬件、驱动与系统策略。
2. 没有用户真实 CPA/OpenAI 图片/WebDAV/MCP 账号。当前使用协议 fixture，不能据此保证某个私有服务兼容；仅支持 Chat Completions，尚无 Responses-only/Anthropic 原生协议。
3. Windows OCR 依赖已安装系统语言；Ubuntu 依赖 Tesseract 中/英文包。截图须遵循系统录屏权限；Wayland 桌面策略可能限制全局快捷键/截图。Windows 提权/受保护窗口可能阻止普通 Ctrl+C；未知来源如实标记。
4. 桌面完全退出后不发送通知；开启后台常驻才会继续运行。Android 强停、权限/省电策略会影响排程，重开会重建。
5. 迁移保留源和旧目标，按当前数据集复制，不合并两套数据库。不可写运行目录需先把程序移到可写位置。极端断电/磁盘故障和所有平台混合 DPI/多屏仍需扩大验证。
6. API Key 默认内置密钥为用户指定的便捷包装，随程序分发，不对获得程序的人保密。支持自定义同步密钥，但未接 OS Keychain，知识正文未 E2EE。AI/WebDAV/MCP 统一使用可选同步密钥自动加密；无设备撤销/集中密钥轮换管理。
7. stdio 只支持桌面；自定义子进程网络由其自身环境变量决定。外部 MCP 中断后不能保证幂等，Agent 会要求确认重试。
8. WebDAV 无全局原子快照；并发/中断可能需后续交换收敛。普通增量不会重下载所有已知文件，显式深度审计可隔离坏块并从可信同 hash 副本修复。
9. 一事件一文件、Depth-1 全名字发现、本地全日志投影；尚无有界日志块、索引投影、增量 Merkle 子树和大库性能验证。CRDT 按整字段保留并发值，不是逐字符文本合并。
10. 完整备份/快照在内存构建；导入上限 256 MiB、单附件 20 MiB。只在校验成功后安全清理恢复冗余/pending；不自动删除历史/孤儿附件，不承诺任何故障下绝不丢失；无可信副本时保留原文件并报错。
11. 全库 AI 分类受上下文上限影响；部分底层错误/模板待继续双语化。中文字体/Mermaid/图编辑包较大，仍有 chunk 提示，低端手机性能待测。
12. 正式 Release 安装升级尚未端到端验证。Android 连续覆盖升级需稳定签名证书；无用户证书的 CI APK 为开发证书。Release 上传使用自动 GITHUB_TOKEN，与可选签名不同。已配置 Minisign 公钥不可跳过验证；Windows Authenticode 未配置。
13. 图标透明1024已验证；生成工具无模型身份字段，无法确认用户指定 image-2.5。
14. 项目无作者指定许可证；正式发行前仍需完整第三方 NOTICE 汇总。

## 0.6 校验边界

- 显式校验会读取全部云端日志、附件、快照，代价高于平时增量同步。连续并发变更最多重试三轮，之后保留已合并内容并提示重试，不清理。
- 无全局原子 WebDAV 锁；校验报告代表已读取的稳定发布集合，无法感知离线设备尚未上传的记录。不可修复的文件/坏快照均保留报错，不以忽略坏文件来报告成功。
- 清理必须有三份已验证快照覆盖同一条恢复记录；新近条目可能暂不清理。损坏原件、迁移备份、历史附件和远端日志保持保留，空间仍会增长，尚无设备撤销/全历史 GC。
- 原生网络权限修复需要安装本轮新包；旧的已安装程序不能靠修改 API 地址或 WebDAV 设置获得新的 capability。

- OpenAI 兼容 API 的根地址通常需包含 `/v1`：根路径 `/models` 的 HTTP 404 与网络权限错误不同。只读未认证探测不能证明凭证或所有接口兼容。


## 0.7 起的编辑与构建边界

- 所见即所得覆盖常用 Markdown、公式、Mermaid、任务和表格；脚注/原始 HTML 保留源码编辑，避免转换丢失。文本仍按整字段 CRDT 合并，不是逐字协作。
- 未保存草稿/标签/聚焦范围按设备保存在本机；保存词条后才参与同步和知识快照备份。切换标签保留草稿与后台页面任务；编辑器撤销栈只在当前挂载视图内保留。
- 大纲和聚焦以顶层块/标题章节为单位；尚无思源的块引用/嵌入、SQL 嵌入、分屏、PDF 标注等完整功能。尚未进行百万字文档或大量标签性能测试。
- Windows、Linux、Android 的 Rust/系统依赖不能共用二进制编译产物。统一 Action 复用前端并分别缓存原生工具链；耗时仍受 Rust 链接、缓存传输和模拟器启动影响，不能承诺固定倍数加速。

## 0.9 模型能力与确认边界

- Tools 未声明仅代表允许尝试，并不证明服务支持；服务端仍可拒绝请求，不自动伪造能力或重试有副作用的工具。全局默认模型由用户选择，不按名称猜测模型适合聊天、图片或 OCR；需要时使用任务单项覆盖。
- 删除回归模拟 Tauri 的 async window.confirm，覆盖全局/词条对话、分类/条目/图连线的等待、取消/关闭/Esc/遮罩及存储失败；另覆盖草稿/MCP/云快照/设备设置取消，确认 Promise 拒绝/抛错由单元测试覆盖，禁止旧 API 的源码扫描防止同类问题复发；0.9.0 已通过 Windows/Ubuntu 实际打包程序和 Android15 模拟器 CI，但尚无 Android 实体手机或真实服务账号兼容测试。


## 0.10 日志与配置边界

- `tool_calls: null` 与可空图片 URL/base64 的兼容由协议回归覆盖；不代表支持任意私有 API 或 Responses-only 模型。日志保留 HTTP 和数据格式错误便于后续核查，不将非法工具调用静默当作成功。
- 日志只在本设备保留最近 100 条/4 MiB，过长字段明确截断，图片二进制不保存。日志导出仍可能含私人提示词和学习材料；已去除运行时已知密钥、敏感字段和 URL 查询参数，不宣称可识别任意正文里的未知机密。日志不参与知识同步。
- 设置在输入停顿约 350 ms 或失焦/离开页面后保存；有效设置独立提交，失败项保留并提示。无效/未完成的输入不是已生效配置，重载或强杀进程前尚未提交的无效草稿不保证恢复。浏览器关闭时异步写入不具有原生退出流程同等保证；正常原生退出/迁移先等待设置与知识草稿落盘。
- 通知/桌面快捷键等仍受系统授权、占用与平台限制；自动保存不会绕过权限。备份、云端恢复、测试连接、日志导出和破坏性操作不是配置自动提交的替代品，继续由用户发起。

- 0.10.0 已发布正式 GitHub Release，安装包和更新元数据已上传并验证摘要；Android 仍是本轮 CI 开发证书，不保证直接覆盖此前开发证书 APK。未配置持久发布 keystore，不宣称 Android 连续签名升级已验证。

## 0.11 统一同步密钥边界

- 默认密钥随程序分发，只是用户指定的便捷包装；知识正文仍非端到端加密。自定义同步密钥保存在本设备加密配置中，各设备需输入相同值。首次连接仍需知道 WebDAV 地址和账号，程序不能从未连接的服务器下载凭证。
- 移除了独立保险箱界面/服务，不删除旧密码密文的不可变历史。旧设备已经保存的 AI/WebDAV/MCP 凭证自动进入统一同步；只有旧密码密文而没有可用本机凭证的记录不会凭空解开或转换，原件保留。
- 并发凭证修改仍按字段 CRDT 保留冲突；密钥修改应在设备完成同步后进行，其他设备需使用相同密钥。原 API 密文格式和现有本机加密封装保持可读。新设备不会因连接 WebDAV 写入空 API Key。

## 0.12 复习边界

- 取消会话保留回答、评分和不可变历史，不视为完成，也不修改 FSRS。停止请求保留当前题目和回答；远端已经开始的运算是否停止由服务端决定，客户端丢弃失效响应。
- 同一运行实例的重复/失效提交由队列条件拦截；多设备同时完成或编辑仍按 CRDT 保留并发版本，不能据此宣称分布式全局锁。混用旧开发版本可能不识别新增的 cancelled 会话阶段，应使用本轮新包。

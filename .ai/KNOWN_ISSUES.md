# 待解决的问题与验证边界

## 平台与真实集成

1. Android 最终 arm64 发布包及 API 35 设备生命周期、通知、文件导出、网络和安装更新仍需完成验证。x86_64 debug（含 Rust/Kotlin 安装器）已编译。云机没有 KVM，软件模拟器不稳定，CI 使用托管 KVM，不能声称本机手机测试通过。
2. Windows 新 workflow/原生驱动/捕获/便携更新助手与 Ubuntu Deb 需实际 CI 验证；旧 Action 的 WiX 中文码页和 Debian 中文包名原因已修正。macOS 不构建。
3. Release 上传无需自定义密钥。Android 无稳定证书时 APK 可安装但跨次运行不能覆盖升级；生产更新必须保持证书。Windows Authenticode、正式包签名/升级尚未实测。Minisign 为可选发布者验证；已配置公钥的包不可回退跳过签名。
4. 真实 CPA/OpenAI 图像/WebDAV/MCP 凭证未配置，当前为模拟服务契约/端到端验证。无 Responses-only/Anthropic 原生协议、无 stdio MCP。
5. Android 通知使用 OS 排程；强制停止应用、权限/省电策略可能抑制，重开会重建。桌面完全退出后通知排程尚未实现。
6. Windows 受保护/提权窗口可阻止普通 Ctrl+C，X11 进程属性不一定存在；Wayland 回退用户已复制内容，未知来源如实标记。跨应用截图尚未实现。
7. 新图标通过透明度/尺寸检查，但当前 imagegen 工具没有模型选择或身份字段，无法确认用户要求的 image-2.5。

## 数据可靠性和规模

8. 物理 SQLite 损坏恢复已有滚动检查点、耐久日志和保留坏库，真实 Linux 测试通过；没有可信恢复副本时会报错，不清空。尚未覆盖所有平台断电/磁盘满/恶意改写/多文件同时损坏。
9. WebDAV 无全局原子快照；并发、中断可能需下一轮交换。普通增量同步不重下载每个已知块；显式深度审计才检测已存在的坏块，修复须有可信同 hash 副本，保留坏内容再写回。
10. 一事件一文件、Depth-1 全量名字发现、本地全日志投影、浏览器整 SQLite 镜像提交。需有界不可变日志块、投影索引、增量 Merkle 子树交换、流式 blob/备份、规模/断电/断点续传测试；不能承诺永久零丢失。
11. 本机凭证存 SQLite，未接 OS Keychain/Keystore；知识正文未 E2EE。凭证 vault 采用用户独立密码加密手动快照，修改凭证后需重新封存；设备分发/撤销/轮换仍待实现。
12. CRDT 为整字段多值寄存器，不是逐字符合并。大型对话数组会形成较大冲突。复习逐次答案编辑产生操作，长库需耐久草稿压缩机制。
13. 完整快照/加密备份在内存构建，导入上限 256 MiB，单附件 20 MiB；不自动清除历史/孤儿附件。云快照可手动校验并合并恢复，空库自动云端 bootstrap 尚未实现。
14. 本地 Agent 写入有原子动作回执，重试不重复；外部 MCP 无法保证幂等，遇到中断要求明确重试。外部服务已经执行但结果未回传时不能推断成功或失败。

## 已核查的依赖审计范围

npm audit 在安全依赖升级后为 0 项。cargo-audit 0.22.2（RustSec 数据库 2026-10-24）报告锁文件中的 rsa 0.9.10（RUSTSEC-2023-0071，无上游修复）和 zip 4.6.1（三项 2026 提取相关 advisory，修复要求 zip>=9）。rsa 在本工程启用的目标特性图中不出现。zip 来自 Tauri updater 的可选 Windows ZIP 功能，已在 Windows 0.3.1 显式禁用该默认 feature，保留 TLS/系统代理，并由 Cargo 重算移除了 zip 锁项；三平台更新只处理 exe/apk/deb。需要通过 cargo tree 的实际 Windows 目标检查，不能因 Linux 默认树不出现就推定所有平台不使用。更新后的 cargo-audit 仅剩未启用 rsa 的 advisory，不能称整个锁文件零 advisory；没有忽略审计条目。GTK 3/glib 等上游链另有维护/unsoundness notice，应用未直接使用被指出的 VariantStrIter API。GitHub Dependabot 剩余 1 moderate 的详情读取权限为 403，不能推定准确归因。

Android GitHub 首轮两种 APK 编译/签名成功，但设备镜像因 runner 磁盘满安装失败；已补充专用 runner 空间清理和原厂镜像缓存。必须在新模拟器实际安装/运行后才标记手机验证通过。

# 给后续 AI 的工作提示词

你正在维护知枢。先阅读 AGENTS.md 与本目录全部状态文档，再检查 git status。延续现有架构，选一个明确的未完成工作完成实现、验证并更新记录。不要把模拟服务测试说成真实多平台验证。UI 可见文字需支持简中和 English；新增 AI 功能必须有可编辑模板、每任务模型、能力约束和默认思考偏好。

数据任务：先定义合并不变量与失败恢复，再修改传输。必须覆盖乱序、重复、断网、损坏、并发删除/编辑、备份恢复。不能删除旧日志，不能复制 SQLite 文件覆盖远端，不能用时间戳取代因果判断。任何自动恢复必须先验证摘要，保留可恢复副本。

原生任务：使用 Tauri 插件的受限能力，不引入任意 shell/任意文件访问接口。Windows 已有显式快捷键 Ctrl+C 与进程采集，X11 有 PRIMARY，其他情况回退未知来源；必须尊重系统保护，不能伪造出处。Android 必须真实编译、安装和生命周期测试后才标为已验证。

交付：运行有意义的测试；报告实际结果、未验证部分与下一项工作。更新 CHANGELOG、STATUS、KNOWN_ISSUES。不要只输出计划或伪实现。

版本：每次实现迭代都运行版本脚本。共享代码改动用 npm run version:bump -- shared；只涉及 Windows/Android/Ubuntu 用对应 windows/android/ubuntu，仅提高该平台 patch。保持所有平台共同 major.minor，不让仓库 tag 导致其余平台无效更新。发布 latest.json 必须保留未构建平台同发布线的 metadata；格式严格为 *_protable.exe、.apk、.deb；不生成Windows安装包。


0.7：只有一个手动 Build and release 入口，默认全平台，前端只编译一次。不要恢复旧平台勾选入口。块编辑须保留 Markdown/JSON 缓存绑定、持久块 ID、聚焦区域外边界；测聚焦全选删除、异步配图和标签切换、保存后立即重启。草稿是设备局部，不能覆盖更新的已保存内容。学习思源交互不等于复制其 AGPL 实现。用户要求历史作者/提交者名 codex，已明确授权本轮强制推送。

0.8：移动布局回归须使用带 isMobile/hasTouch 的真实移动浏览器上下文，检查 body.scrollWidth 不超过 documentElement.clientWidth，并点击底部导航。长大纲在自动最小尺寸的 1fr 网格中曾撑宽页面；保持 minmax(0, 1fr) 与子项 min-width:0。Android 使用 ADB 截屏，避免全页截图改变 WebView 视口。

## 持续规格与逐项验收（用户明确要求）

每次开始先读 `.ai/初始提示词.txt`。所有新提示词、需求、修正及验收规则及时合并进该文件，使其独立描述整个程序的复现规格；本维护要求本身也必须保留在提示词中。持续列出全部编号需求，逐项区分待实现、已接入待验收、已验收和已发布，逐项完成并核对细节。新增消息默认追加/修正当前任务，不能遗忘未完成项；未测试的代码不标为完成。

最新用户约定：普通提交/push/PR不自动运行测试，不因每次提交重复全量；完整单元/脚本/浏览器回归仅在Build前置阶段运行，失败禁止打包。原生更新边界在打包前验证，包/签名/完整性与必要生命周期仍门禁。Android生成工程必须显式覆盖软件普通/圆形/自适应图标，禁止模板圆圈残留；原生WebView关闭整页缩放，不吞触摸事件。

README保持简洁的使用/开发入口，及时同步当前平台、配置和构建规则；历史排错/验收明细放.ai，不把流水账、冗长示例和过时说明堆进README。

0.19最新规则：Windows只发布单文件protable.exe，禁止安装器；数据默认系统应用目录，portable只决定_data，不影响更新产物。使用release-windows编译期体积优化，不加运行时解压器，实际测量文件大小/启动。星图增加可编辑graph任务模板、全库分批关联/预览选择/防循环与过时保护、图读写/布局/批量坐标工具；左键框选整组拖动原子保存。分类显示完整路径+修改按钮，菜单色块醒目而实际背景柔和。对应106条规格和ITERATION_019。

Windows实际命令：`tauri build --no-bundle -- --profile release-windows`；profile经Cargo参数转发，不能作为Tauri参数。先用已安装CLI解析回归检查，避免完成原生编译后才发现无效命令。

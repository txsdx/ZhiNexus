- Windows、Linux、Android 的 Rust/系统依赖不能共用二进制编译产物。统一 Action 复用前端并分别缓存原生工具链；耗时仍受 Rust 链接、缓存传输和模拟器启动影响，不能承诺固定倍数加速。

## 0.9 模型能力与确认边界

- Tools 未声明仅代表允许尝试，并不证明服务支持；服务端仍可拒绝请求，不自动伪造能力或重试有副作用的工具。全局默认模型由用户选择，不按名称猜测模型适合聊天、图片或 OCR；需要时使用任务单项覆盖。
- 删除回归模拟 Tauri 的 async window.confirm，覆盖全局/词条对话、分类/条目/图连线的等待、取消/关闭/Esc/遮罩及存储失败；另覆盖草稿/MCP/云快照/设备设置取消，确认 Promise 拒绝/抛错由单元测试覆盖，禁止旧 API 的源码扫描防止同类问题复发；0.9.0 已通过 Windows/Ubuntu 实际打包程序和 Android15 模拟器 CI，但尚无 Android 实体手机或真实服务账号兼容测试。


## 0.10 日志与配置边界

- `tool_calls: null` 与可空图片 URL/base64 的兼容由协议回归覆盖；不代表支持任意私有 API 或 Responses-only 模型。日志保留 HTTP 和数据格式错误便于后续核查，不将非法工具调用静默当作成功。
- 日志只在本设备保留最近 100 条/4 MiB，过长字段明确截断，图片二进制不保存。日志导出仍可能含私人提示词和学习材料；已去除运行时已知密钥、敏感字段和 URL 查询参数，不宣称可识别任意正文里的未知机密。日志不参与知识同步。
- 设置在输入停顿约 350 ms 或失焦/离开页面后保存；有效设置独立提交，失败项保留并提示。无效/未完成的输入不是已生效配置，重载或强杀进程前尚未提交的无效草稿不保证恢复。浏览器关闭时异步写入不具有原生退出流程同等保证；正常原生退出/迁移先等待设置与知识草稿落盘。
- 通知/桌面快捷键等仍受系统授权、占用与平台限制；自动保存不会绕过权限。备份、云端恢复、测试连接、日志导出和破坏性操作不是配置自动提交的替代品，继续由用户发起。

- 0.10.0 已发布正式 GitHub Release，安装包和更新元数据已上传并验证摘要；Android 仍是本轮 CI 开发证书，不保证直接覆盖此前开发证书 APK。未配置持久发布 keystore，不宣称 Android 连续签名升级已验证。

## 0.11 统一同步密钥边界

- 默认密钥随程序分发，只是用户指定的便捷包装；知识正文仍非端到端加密。自定义同步密钥保存在本设备加密配置中，各设备需输入相同值。首次连接仍需知道 WebDAV 地址和账号，程序不能从未连接的服务器下载凭证。
- 移除了独立保险箱界面/服务，不删除旧密码密文的不可变历史。旧设备已经保存的 AI/WebDAV/MCP 凭证自动进入统一同步；只有旧密码密文而没有可用本机凭证的记录不会凭空解开或转换，原件保留。
- 并发凭证修改仍按字段 CRDT 保留冲突；密钥修改应在设备完成同步后进行，其他设备需使用相同密钥。原 API 密文格式和现有本机加密封装保持可读。新设备不会因连接 WebDAV 写入空 API Key。

## 0.12 复习边界

- 取消会话保留回答、评分和不可变历史，不视为完成，也不修改 FSRS。停止请求保留当前题目和回答；远端已经开始的运算是否停止由服务端决定，客户端丢弃失效响应。
- 同一运行实例的重复/失效提交由队列条件拦截；多设备同时完成或编辑仍按 CRDT 保留并发版本，不能据此宣称分布式全局锁。混用旧开发版本可能不识别新增的 cancelled 会话阶段，应使用本轮新包。

- 0.12.0 已完成三平台实包/Android15 模拟器测试及正式 Release，清单和四个安装包的摘要已验证。Android 仍为 CI 开发证书 APK，连续覆盖升级/实体机以及真实私有 AI/WebDAV 账号兼容性仍遵循既有验证边界。

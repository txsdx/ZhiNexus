# 待解决的问题与验证边界

## 平台和集成（优先）

1. Android CI 和真机：首次编译、通知权限/后台任务、键盘与安全区、SQLite 生命周期、文件导出/恢复、联网与 TLS、APK 签名。当前云环境没有 SDK/设备，workflow 只是入口。
2. 关闭应用后的复习通知：需要 Android WorkManager/AlarmManager 和桌面平台排程策略，不能依赖 JS interval；本版只在进程运行时提醒。
3. 原生启动验证：Linux check/debug build 通过。云机没有系统安装的 WebKit 4.1，只能下载并验证 Debian 包到 `/workspace/toolchains/sysroot`；WebKit helper 的编译期绝对路径仍在 `/usr/lib/...`，因此运行检查受环境阻塞。需在正常系统依赖安装的机器验证，不修改/伪造系统库、不关闭 sandbox 绕过。
4. 真实服务兼容性：没有配置 API/WebDAV/MCP 凭证，只做模拟 HTTPS 契约验证。分别验证 CPA 扩展、普通 OpenAI 兼容网关、图像输出、MCP SSE/会话、具体 WebDAV（目录编码、207、大小限制）后才能记为实测。
5. 签名发布：没有 Release/密钥；开发配置 `updater.pubkey=""`、`endpoints=[]` 允许正常启动但不可更新。发布 CI 写入真实公钥与清单地址；Android 仍需应用内 APK 更新安装流程。macOS 公证/Windows 代码签名尚未配置。
6. 来源捕获：全局快捷键只读取剪贴板，不是跨进程选区/截图采集；来源进程未知。需要各 OS 权限和专门实现。

## 数据可靠性和规模

7. SQLite 物理损坏不自动重建；启动校验失败保留原库并显示错误。需要独立设备配置、滚动已验证本地快照、恢复到新文件、原子切换、保留损坏副本的恢复流程。
8. WebDAV 没有全局原子快照。并发上传或中断可需下一轮完成；缺因果依赖会拒绝不完整批次。远端已知 hash 的坏块不会在普通增量同步中全部下载检测。需要显式深度审计和可证明的修复来源。
9. 目前一事件一文件、Depth-1 全量列表、本地全日志投影，浏览器每次提交导出整库。需有界不可变日志块、SQLite 投影索引、增量树交换、断点续传/持久 outbox 和规模/断电测试。不要以当前实现承诺“永久零丢失”。
10. 本地密钥存 SQLite，未接入 Keychain/Keystore；WebDAV 学习正文未做 E2EE。凭证不能写到明文日志；已增加用户密码加密的凭证 vault，可跨设备同步后显式解锁。仍需设备密钥分发、撤销、轮换、OS安全存储与更完整的威胁模型。
11. MCP 配置可通过加密 vault 分发；通知和同步周期保持设备级偏好。Vault 是手动封存的凭证快照，修改凭证后需重新封存；不自动保存主密码。
12. 同字段文本不是逐字符 CRDT，整字段多值冲突保留；词条历史和数据库通用冲突面板可选择字段版本。长对话数组可能形成较大冲突版本。
13. 复习答案逐次编辑进入日志以保证退出恢复；长库应改用耐久草稿 + 合并提交，避免日志过快增长。
14. 完整快照/备份目前内存构建，备份导入限制256 MiB、单附件20 MiB。需流式加密/恢复和更大数据集验证。历史与孤儿附件不自动删除。
15. 快照现用于手动导出/上传，远端快照发现/自动启动恢复、设备退役后的安全历史回收尚未实现。
16. 字段级并发删除保留历史；隐藏状态采用确定选择，需更明确的删除/编辑冲突 UX。审计显示每个 patch，尚无可视化行级 diff。

## 体验与维护

17. 运行时 AI 默认模板为中文任务说明，用户可以改；部分错误字符串尚未双语化。示例知识不是严格审校教材。
18. Markdown 禁止原始HTML与外部图片自动加载；需外部图片时先导入本地。Mermaid/KaTeX/中文字体增加安装包体积，首次加载已按页/图延迟，仍需继续包体优化。
19. 分类目前支持增加大类/子类，重命名/移动/删除的完善 UI 尚未做。AI 全库整理会受模型上下文大小限制，未实现批处理大库分类。
20. Agent 有限工具循环和逐轮持久化；尚无带幂等键的 durable tool outbox。进程恰在工具写成功/结果持久化之间终止时，应先检查日志再重试。

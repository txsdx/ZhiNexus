# 知枢 · ZhiNexus

<img src="public/app-icon.png" alt="知枢图标" width="88" />

本地优先的个人知识库。记录概念、整理解释、与 AI 讨论，并用间隔复习巩固理解。

## 下载

在 [最新 Release](https://github.com/txsdx/ZhiNexus/releases/latest) 下载对应文件：

| 平台 | 文件 |
|---|---|
| Windows x64 | `*_protable.exe` 单文件程序，无需安装 |
| Ubuntu 24.04+ x64 | `.deb` |
| Android 15+ arm64 | `.apk` |

Windows 需要 WebView2 运行时（Windows 10/11 通常已安装），默认将数据存入系统应用数据目录。需要便携存储时：在 exe 同目录创建无扩展名的空文件 `portable`，数据会保存在同目录 `_data/`；切换模式前退出程序，两套数据独立，也可在数据库设置中迁移。两种模式均直接替换 exe 更新。

旧安装版请先从托盘完全退出，再启动下载的单文件 exe，系统目录中的数据会沿用。

当前 Android 包使用开发签名，覆盖旧 APK 取决于签名是否一致。更新前保留数据备份，不要为刷新图标删除应用数据。

## 主要功能

- **知识记录**：Markdown 块编辑、公式、Mermaid、表格和图片；左侧大纲、多标签和本机草稿恢复。
- **分类整理**：完整分类路径、小分类树选择和层级拖拽、右键操作和柔和背景色；删除可保留并上移内容，也可整树删除。
- **AI 助手**：流式对话、词条右侧栏、划词与草稿上下文、任务队列和并发限制；支持软件工具及 MCP，写入前审阅。
- **知识星图**：AI 分析全部条目的依赖、递进和关联，先预览再应用；左键框选批量移动，布局自动保存。
- **间隔复习**：FSRS 调度、实际回忆四档自评、交互遗忘曲线和可配置保留目标；新词条默认已经学会，不立即进入复习。
- **多端同步**：WebDAV/SFTPGo、压缩批次、内容校验和旧文件回收；设置自动保存，右上角点击立即同步。
- **快速捕获**：图片粘贴/拖入、MD/TXT/DOCX转Markdown、本机草稿恢复；桌面快捷键打开置顶、可缩放的独立窗口。
- **桌面操作**：托盘、截图/OCR、自定义右键菜单、Alt+左右键与鼠标侧键位置导航。

## 开始使用

1. 点击“记录新知识”，填写名称、材料并选择分类。
2. 在“设置与偏好 → AI 与模型”填写服务地址和密钥，选择全局默认模型；任务可单独覆盖。使用原始模型 ID，接口地址按服务要求填写，通常包含 `/v1`。
3. 在词条中展开“AI 对话”，或划词后提问。AI 修改先进入本机草稿，保存词条后才参与同步。
4. 在“数据库与云同步”配置 WebDAV。自定义同步密钥可留空使用默认方案；多设备使用自定义值时保持一致。所有设备请使用同一发布版本。
5. 在复习设置中调整目标保留率，默认 90%。按实际回忆选择“忘记、困难、记得、轻松”，曲线和后续计划随之更新。

设置会自动保存。AI 请求的提示词、拼接完整输出和错误可在“日志”页查看。

## 开发与构建

技术栈：Tauri 2、React、TypeScript、SQLite；编辑器使用 Tiptap，调度使用 ts-fsrs。

需要 Node.js 24、稳定版 Rust 及 [Tauri 平台依赖](https://v2.tauri.app/start/prerequisites/)。Android 使用 JDK 21、NDK 27.2，最低 API 35，编译 SDK 由当前 Tauri 模板决定。

```bash
npm ci
npm run dev        # 浏览器开发
npm run tauri dev  # 原生桌面开发
```

发布构建在 **Actions → Build and release → Run workflow** 启动，统一构建三平台。只有“发布 Release”和“保存为草稿”两个选项。

- 普通提交、push/PR 不自动测试；单元、脚本和浏览器回归在 Build 前集中运行，失败阻止打包。
- 前端只编译一次，三个原生目标校验后复用。原生更新回归、Windows 实包验收、包/签名/摘要检查仍保留。
- Android 默认只编译 arm64，不运行模拟器。Ubuntu 图形诊断按需复用指定 Build 的 DEB，不重复编译。
- 程序启动后可后台检查和下载更新；Windows 正常退出后直接替换 exe，Android/Ubuntu 安装仍遵循系统授权。
